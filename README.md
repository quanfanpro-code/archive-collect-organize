# 🗂️ 资料包整理小助手

> 一堆压缩包、一堆文件夹、一堆同名文件，十分钟理成能直接交出去的资料包。

---

## 🤔 这东西是干什么的

你从客户、同事、或者上一个项目那里拿到一个文件夹，里面通常是这样的：

- 七八个压缩包，名字五花八门 📦
- 十几个文件夹，有的按年份分，有的按部门分 📁
- 根目录散着一堆表格、图片、报告 📊
- 压缩包解开一看，一半文件文件夹里已经有了 😑
- 另一半名字一样、内容不一样，不知道该留哪个 😵

这个小助手就干一件事：**把压缩包里的东西和文件夹里的东西一一对照，缺的补进去，重复的不重复放，撞名的按修改时间留下新的，旧的挪到一边，最后给你一张清单。**

从头到尾，**它不会覆盖你任何一个已有文件，也不会删你任何一个压缩包。** 🛡️

## 🧠 它内部是怎么想的（不懂技术也能看明白）

流程分五步。前四步只往目录里**加东西**，绝不改已有的东西。

**第一步 · 先看，不动手** 👀
把你那个文件夹从头到尾扫一遍：几个压缩包、里面各有多少文件、外面已经有哪些文件。这一步只读不写，随便跑，跑十次也不会动一个文件。

**第二步 · 把压缩包解开，但解到别处** 📦
所有压缩包统统解开，放在系统的临时文件夹里，不放在你的资料目录里。原因很实在：解压会留下痕迹，直接解在资料目录里，回头你分不清哪些是正式的、哪些是解压出来的。

顺带修一个老坑：老式压缩包里的中文文件名，直接解开常常变乱码，这里会自动还原。

**第三步 · 一个一个对，缺的才补** 🔍
从临时文件夹拿出一个文件，看你目录里有没有同名的：

- 有同名的，内容**完全一样** → 跳过，不重复放
- 有同名的，内容**不一样** → 两份都留。压缩包来的那份改名叫「原名_补-压缩包名」，你的原件一动不动
- 没有同名的 → 复制进去

名字大小写不同、全角半角不同、末尾多一个空格，在电脑眼里是同一个名字，这里也认得出，不会悄悄把你那份盖掉。

**第四步 · 撞名的那几对，比时间** ⏰
这一步是重点，也是最多人踩坑的地方。

你可能会想：直接看文件的「修改时间」不就行了？不行。文件被解压、被复制、被挪位置，修改时间都会被刷成「刚才」。我这回实测，从压缩包里出来的文件，修改时间全是同一个时刻，那是我解压的时间，不是文件真正被改过的时间。

那看什么？**看压缩包里记的时间。** 压缩包在打包那一刻，会把每个文件当时的修改时间一起记进去，解开之后这个记录不会变。所以只比两个数：

- 压缩包里记的时间
- 你目录里那份文件的修改时间

哪个新，哪个就是新的。差不到一分钟的，说明是同一批文件，两个都不动，只在清单里记一笔。

**第五步 · 旧的那份挪进「_旧版本」文件夹** 🗃️
被判为旧的那份不删除，而是挪到同一目录下的「_旧版本」文件夹。这样你的资料目录一个位置只有一份正本，看着干净；旧的那份就在旁边，随时能翻出来核对。

做过的每一步都会写进清单：哪份进了「_旧版本」、从哪个压缩包来的，一查就知道，能原样倒回去。

## 🚀 怎么用（照着做就行）

### 第一步：确认电脑里有 Python 🐍

这是个免费的运行环境，装没装很好判断：打开「命令提示符」窗口，输入 `python --version` 再回车。跳出一行版本号就是有；提示找不到，就去官方网站下载安装，安装时勾上「Add Python to PATH」那个选项。

### 第二步：先预演，看它打算干什么 👀

在命令提示符里输入下面这一行。中文部分换成你自己的文件夹位置，引号要保留：

```
python "D:\BaiduSyncdisk\workbuddy skills\archive-collect-organize\scripts\archive_sync.py" --root "你的资料文件夹位置"
```

回车后屏幕会出现几个数字：压缩包几个、待复制几个、已存在跳过几个、冲突几对、失败几个。同时你的资料文件夹里会多出一个「_整理报告」文件夹，里面有详细记录，用记事本就能打开。

**这一步没有动你任何一个文件，可以放心多跑几次。**

### 第三步：确认没问题，再真正执行 ⚡

在上一条命令末尾加一个空格加 `--apply`，再回车：

```
python "D:\BaiduSyncdisk\workbuddy skills\archive-collect-organize\scripts\archive_sync.py" --root "你的资料文件夹位置" --apply
```

这次才真正往目录里复制文件。

### 第四步：处理撞名的那几对 ⏰

先预演：

```
python "D:\BaiduSyncdisk\workbuddy skills\archive-collect-organize\scripts\resolve_conflicts.py" --root "你的资料文件夹位置"
```

会生成一份「decisions.csv」，用表格软件打开，每行是一对同名文件，列出两边的时间、留下哪份、做了什么。看完觉得没问题，再加 `--apply` 执行：

```
python "D:\BaiduSyncdisk\workbuddy skills\archive-collect-organize\scripts\resolve_conflicts.py" --root "你的资料文件夹位置" --apply
```

### 第五步（可选）：把根目录散文件归位 🧹

想让「花名册」自动进人事目录、「订单」自动进销售目录，需要先准备一份归类规则文件放在资料目录里，再用带 `--scatter` 的命令执行。规则怎么写，打开项目里的 `config/mapping.example.json` 照着改关键字即可。

## ⚖️ 判定规则一览

| 情况 | 怎么处理 |
|---|---|
| 同名、内容完全一样 | 跳过，不重复放 |
| 同名、内容不同，时间差超过一分钟 | 时间新的留下，旧的进「_旧版本」 |
| 同名、内容不同，时间差不到一分钟 | 两个都不动，清单记一笔 |
| 名字只差大小写或全半角 | 当成同一个名字，不会静默覆盖 |
| 路径太长或名字有非法字符 | 跳过这一个，其余照常，清单里列出 |

## 🛡️ 四条安全承诺

1. **不覆盖**：你已有的文件，一个都不会被盖掉。撞名就两份并存。
2. **不删除**：压缩包原件全部留着；被判为旧的只是挪进「_旧版本」，不是删掉。
3. **可倒回**：每一步都记在清单里，从哪挪到哪清清楚楚，需要时原样挪回。
4. **能预演**：不加执行参数只出报告，随便跑，不动文件。

## ❓ 常见问题

**问：会不会把我原来的文件弄乱？**
答：不会。预演阶段只读不写；执行阶段只往目录里加文件，不加进已存在的同名文件里；旧版只是换个地方待着。

**问：压缩包里的文件比我的新，会怎样？**
答：新的那份顶到正本位置、用回原来的名字；你原来那份进「_旧版本」。清单里写得很清楚。

**问：为什么它判断的结果和我想的不一样？**
答：最常见的原因是你那份文件在打包之后被复制或挪动过，修改时间被刷成「最近」，于是被判成更新。这种情况不丢文件，只是正本没换，你去「_旧版本」把新的那份拿回来改个名字就行。

**问：能处理加密的压缩包吗？**
答：不能。加密包和分卷包要用解压软件手工解开，放进目录再跑。

**问：能整理多大的资料包？**
答：没有硬上限，但要预留跟压缩包总大小差不多的临时空间。几百个包、几十个吉字节的量级请分批跑。

**问：会把我的表格内容读出来看吗？**
答：不会。它只看文件名、大小、内容指纹和时间，从不去解析文件里面写了什么。

**问：中文文件名会不会乱码？**
答：不会。老式压缩包用中文编码存名字，程序会自动还原。我在真实资料上试过近九百个文件名，全部正常。

**问：跑坏了怎么办？**
答：所有移动都有记录。打开「_整理报告」里的清单，按记录反向挪回去；压缩包原件一直在，最坏情况重新解压一遍。

**问：能同时整理好几个文件夹吗？**
答：一次一个。不同资料包的分类逻辑往往不同，混着跑容易放错位置。

## 👤 适合谁

- 经常收到「一堆压缩包」的财务、审计、法务、投标、项目管理岗位
- 不想学编程，但愿意照着步骤敲两三行命令的人
- 需要把资料交给别人，并且能说清「哪些动过、哪些原封不动」的人

## 🚫 不适合谁

- 想让它读合同内容、判断哪份有法律效力的人（它只比时间，不做判断）
- 想让它全自动删重复文件的人（它不删任何东西）
- 想整理整个硬盘的人（只对资料目录用）

## 🙏 一点说明

这个工具是在整理一份真实的尽调资料包时做出来的。那次整理暴露了两个真问题：文件时间会被解压刷掉，同名不同内容的文件靠人眼分辨极容易出错。所以这里宁可慢一点、多留一份，也不赌一把覆盖掉。
