# 资料包整理

把多个压缩包、散文件及原有文件夹，整理成按业务用途查找的资料目录。解压只是中间步骤；最终必须把不同包里的同类资料合并归位。

例如，两包同批次设计成果分别装着建筑、结构和强电、人防资料，整理后应进入同一个设计目录，并保留专业、地块和附件子目录。分类名称依据实际资料确定，不固定套用七类或某个项目的目录。

## 默认行为

- 保留原文件名、必要子目录和原始压缩包。
- 跨目录同名或同内容文件均分别保留，不自动去重。
- 不按修改时间判断新旧，不自动归档所谓旧版。
- 只有落到同一完整目标路径才构成位置冲突；增加来源子目录保留双方，不改原文件名。
- CAD等图纸按目录和文件名归类，不读取内部图形、不安装查看环境。
- 按本次会话约定处理备份；用户明确以原压缩包作备份时，核对涵盖范围后直接移动，不再重复复制整个资料目录。

## 工具分工

| 工具 | 用途 |
|---|---|
| `scripts/archive_sync.py` | ZIP解压补缺，可配置落点；只完成此步不能报告整理完成 |
| `scripts/业务归类.py` | 按AI已核对的完整清单移动归位，检查漏项、撞名及原名保留，输出逐文件核验结果 |
| `scripts/resolve_conflicts.py` | 兼容旧补文件的可选核查；默认不判新旧，用户另行授权才使用`--by-time` |

具体归位清单格式与调用见 [SKILL.md](SKILL.md)。AI负责盘点、制定分类及生成清单，用户不需要手写规则或运行命令。已有解压结果直接归位，不重复解压。

## 产出及验证

根目录展示业务分类，原始压缩包集中保留，内部报告放在`_整理报告`。业务归位报告每次新建独立目录，包含`归位明细.csv`、`结果.json`和执行时的移动记录。空的旧目录可集中收存，不自动删除。

完成时说明每类文件数、同类资料合并情况、逐文件核验结果和未处理项。内嵌压缩包是否展开必须如实列出；不因外层解压成功而报告全部处理完成。

## 本机验证

使用已核实的本机Python运行`tests/test_skill.py`。测试保留样本，不自动删除，不触碰真实资料目录；可设置`ACO_TEST_ROOT`指定样本存放目录。
